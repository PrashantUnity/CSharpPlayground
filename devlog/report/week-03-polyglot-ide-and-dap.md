# What We Built: Week 3 (Polyglot IDE & DAP Debugging)

**Dates:** September 27, 2026 – October 2, 2026

## 🌟 The Big Picture
We launched releases **v2.0.0** and **v2.0.1**, expanding from a C# playground into a full 9-language IDE powered by the Debug Adapter Protocol (DAP), interactive 3D visualizations, and an embedded local web server.

---

## ⚡ Key Highlights

- **9 First-Class Languages**: Added support for C#, Python, JavaScript/Node, Java, C++, Go, Rust, F#, and SQL.
- **Universal DAP Debugger**: Standardized debugging engine with stepping (F10/F11), breakpoints, call stacks, and collection visualizers across all languages.
- **FryServer HTTP Studio**: Embedded web server engine to launch and inspect local APIs and web servers directly inside the IDE.
- **3D Charting & Voxels**: Interactive 3D surface and voxel charts with camera controls and data export.
- **Desktop Native Menus**: System application menu bar on macOS and Windows with keyboard shortcuts.
- **Find-in-Files & Virtualized Tree**: Fast multi-threaded project search and smooth lazy-loaded file explorer for 50,000+ file projects.
- **Releases v2.0.0 & v2.0.1**: Major polyglot milestone shipped with automated environment checks.
