# What We Built: Week 4 (FrySharp Rebrand & AI Composer)

**Dates:** October 3, 2026 – October 4, 2026

## 🌟 The Big Picture
We rebranded the entire project to **FrySharp**, introduced a floating AI agent composer with screen capture protection, built a complete plugin SDK with a playable Snake game, and added integrated Git version control.

---

## ⚡ Key Highlights

- **Rebranded to FrySharp**: Official new brand name, updated UI styling, and native packaging for macOS (`.dmg`) and Windows (`.msix` / `.exe`).
- **Floating AI Composer**: Draggable AI chat window with `@` context mentions for code and native screen capture protection to prevent leaking API keys on stream.
- **Plugin System & Snake Game**: Community plugin framework allowing Git installs (`%ext install`), highlighted by a playable retro Snake game running directly inside the IDE.
- **Built-in Git Source Control**: View status, stage files, switch branches, and inspect color-coded side-by-side diffs inside the studio.
- **Rich File Previews**: One-click live Markdown preview and interactive CSV/TSV table viewer with JSON export.
- **Dynamic Languages & Dart**: Support for dynamic language extensions and Dart integration.
