# Run a script

Open a `.cs`, `.csx`, `.py` or `.js` file and press the play button in the editor title, or `Ctrl+Alt+R`.

It runs in a terminal: type to answer `Console.ReadLine()` or `input()`, `Ctrl+C` stops it, and errors in the output are links to the file. Tables and charts a program shows appear in the **Results** panel.

**FrySharp: New Scratchpad** opens a notebook that keeps its kernels, and **Send Selection to Scratchpad** runs the selected code in it.
