# Show a table or a chart

`Display` shows more than text. In C#:

```csharp
Display.Table(people, "People");
Display.LineChart(new double[] { 1, 4, 9, 16 }, "Squares");
```

Tables sort and filter and copy as CSV or JSON. Charts, 3D plots, ECharts, images, HTML and Markdown are drawn in your theme.

Type `fry` in a cell to insert one of these as a snippet, in C#, Python or JavaScript.
